# Changelog

All notable changes to this project are documented in this file.

## [1.1.1] - 2026-11-09

### Added

- First public release.
- Reproducible, dependency-free ZIP builder and verifier.
- English and Russian documentation.
- Explicit compatibility, power, thermal, and uninstall guidance.

### Changed

- Truncate `service.log` on each boot instead of appending indefinitely.
- Report a direct error when acquiring the kernel wakelock fails.
- Set the public module author to `sergej19882906`.
