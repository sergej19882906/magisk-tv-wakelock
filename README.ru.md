# Magisk TV Wakelock

[English version](README.md)

Небольшой Magisk-модуль, который не даёт поддерживаемым Android TV-устройствам переходить в глубокий сон. На late-start стадии Magisk он захватывает legacy kernel wakelock с именем `tv_wakelock`.

Модуль не запускает постоянный пользовательский процесс, не изменяет `/system`, не использует Zygisk и не обращается к сети.

## Важное предупреждение

Запрет глубокого сна может увеличить энергопотребление в режиме ожидания и температуру устройства. Длительное использование способно ускорить износ компонентов. После установки контролируйте температуру и потребление энергии.

Модуль блокирует только suspend ядра. Он **не гарантирует**, что экран, HDMI, CEC-устройства, сетевые интерфейсы, приложения или периферия останутся активными. Экран может выключаться как обычно.

## Требования

- Android TV с root и Magisk.
- Доступные для записи legacy-интерфейсы wakelock:
  - `/sys/power/wake_lock`
  - `/sys/power/wake_unlock`
- Ядро и SELinux-политика, разрешающие Magisk root обращаться к этим интерфейсам.

Проверено на:

- Xiaomi `MiTV-AFKR0`
- Android 14 (SDK 34)
- Magisk 31.1
- SELinux enforcing

Другие устройства и версии могут работать, но пока не проверены.

## Установка

1. Скачайте устанавливаемый ZIP и `SHA256SUMS` из последнего [релиза GitHub](https://github.com/sergej19882906/magisk-tv-wakelock/releases/latest).
2. Проверьте контрольную сумму ZIP.
3. Откройте Magisk, выберите **Модули → Установить из хранилища** и укажите скачанный ZIP.
4. Перезагрузите устройство.

Не устанавливайте автоматически созданный GitHub-архив **Source code**. Это не пакет Magisk-модуля. Используйте ZIP, приложенный к релизу.

## Проверка

После перезагрузки выполните:

```sh
su -c 'grep -w tv_wakelock /sys/power/wake_lock'
```

Ожидаемый результат:

```text
tv_wakelock
```

Модуль также записывает один диагностический журнал на каждую загрузку:

```sh
su -c 'cat /data/adb/modules/tv_wakelock/service.log'
```

При успешном запуске в нём будет:

```text
success: kernel wakelock tv_wakelock acquired
```

## Отключение и удаление

- **Отключение:** отключите модуль в Magisk и перезагрузите устройство. Уже захваченный wakelock может оставаться активным до перезагрузки.
- **Удаление:** удалите модуль через Magisk и перезагрузитесь. `uninstall.sh` также пытается освободить wakelock сразу.

Аварийное ручное освобождение на поддерживаемом ядре:

```sh
su -c 'echo tv_wakelock > /sys/power/wake_unlock'
```

## Решение проблем

### `wake_lock is not writable`

Интерфейс ядра отсутствует, доступен только для чтения или заблокирован SELinux-политикой устройства. Модуль намеренно не устанавливает широкие SELinux-исключения. Отключите или удалите его.

### Wakelock удерживается, но сеть или HDMI всё равно отключаются

Kernel wakelock блокирует только глубокий suspend. Прошивка производителя может отдельно отключать сеть, HDMI, CEC, приложения или периферию.

### Устройство нагревается или потребляет слишком много энергии

Отключите либо удалите модуль и перезагрузите устройство. Это ожидаемый возможный эффект запрета suspend.

## Сборка из исходников

Единственная зависимость — Python 3:

```sh
python scripts/build.py
python scripts/verify.py
```

Результаты:

```text
dist/magisk-tv-wakelock-vX.Y.Z.zip
dist/SHA256SUMS
```

Сборщик использует строгий список файлов, фиксированные даты и Unix-права, а также отключённое сжатие, поэтому повторные сборки побайтово идентичны.
